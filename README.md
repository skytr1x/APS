# Another Plugin System (APS)

Elyx-плагин для exteraGram с собственной системой плагинов. Плагины пишутся на Rust, собираются в WebAssembly через [APS SDK](https://github.com/skytr1x/APS-SDK) и добавляются в клиент одним файлом `.apl`. Имя, автор, версия и описание хранятся в метаданных внутри файла.

## Установка

1. Установите APS в exteraGram и откройте его настройки.
2. Установите SDK, когда APS предложит это сделать. Без SDK плагины не запускаются.
3. Откройте файл `.apl` в exteraGram, затем включите плагин в настройках APS.

## Ограничения

- У WASM-плагинов нет ограничений по времени и памяти. Бесконечный цикл или утечка могут подвесить клиент, поэтому включайте только доверенные плагины.
- SDK скачивается из ветки `main` на GitHub без проверки подписи или хеша. Он выполняет Python-код внутри клиента, поэтому устанавливайте SDK, только если доверяете репозиторию (а то-есть скачивать плагин нужно только из [Телеграм Канала](https://t.me/sktrxdev) разработчика).
